# Support

UFGU is beta software maintained as availability permits.

Use a GitHub bug report for reproducible plugin faults. Include one complete
`UFGU.log` launch session after replacing usernames, profile names and
installation paths with `<redacted>`. Keep every line and all non-path values.
Also include Skyrim and SKSE versions, GPU and driver, provider settings,
resolution, refresh rate, ENB or ReShade state, reproduction steps, and results
with frame generation, upscaling, and UFGU disabled.

Use a feature request for a focused proposal that does not fit an existing
issue. General setup questions belong in GitHub Discussions when discussions
are enabled.

Do not post vulnerabilities, malicious files, unsanitized logs, credentials or
personal paths in a public issue. Follow [SECURITY.md](SECURITY.md) for private
security reporting.

Unsupported combinations include Community Shaders, another upscaler or frame
generator, DLSS Enabler, OptiScaler, and other presentation-hook replacements.
Reports must first be reproduced without those conflicts.
